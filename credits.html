Sinoky — Speak Chinese where it matters · Last updated: 2026-09-13
Why this page exists. Sinoky is built on the work of others. This page lists every third-party component and data set it uses, together with the licence it is used under, so that the required copyright notices travel with the product.

1. Writing & stroke order

  • Hanzi WriterMIT — stroke animation and quiz engine. Copyright its respective authors. vendor/hanzi-writer.min.js
  • Make Me a Hanzi — stroke order data (data/strokes/*.json), derived from glyphs of the Arphic Public Fonts. Distributed under the Arphic Public License.
  • Arphic Public Fonts — the glyph source for the stroke data above. The full licence text is retained unaltered as ARPHICPL.TXT in the root of the product, as required by §1 of that licence.

2. Pinyin

  • pinyin-proMIT — pinyin conversion, tone marks and heteronym handling. vendor/pinyin-pro.bundle.mjs

3. QR codes

  • qrcode-generator v1.4.4MIT — QR encoding for share cards. Copyright © 2009 Kazuhiko Arase. Inlined into index.html with the original copyright header preserved verbatim at the head of the block.
  • “QR Code” is a registered trademark of DENSO WAVE INCORPORATED.

4. Debugging

  • vConsoleMIT — on-device debug console, loaded only in debug builds. Copyright Tencent. vendor/vconsole.min.js

4b. UI icons

  • LucideISC — line icon set used for the interface glyphs. assets/icons/ui/ (each file keeps its original license header).

5. Audio

  • Scene and tone audio — recorded by the author of Sinoky and owned by this project.
  • Microsoft Edge text-to-speech — used at runtime to voice phrases that have no recording. Generated audio is streamed for playback only, never stored, and is not part of the recorded corpus.

6. Fonts used for rendering

Sinoky does not ship any font files. Chinese text is rendered with the fonts already installed on your device (falling back through a CJK stack such as Noto Sans CJK, PingFang SC, or Microsoft YaHei). No webfont is downloaded and no font file is redistributed.

7. Content

All 31 learning scenes, the HSK-graded flashcard sets, and every English/Chinese sentence pair were written for Sinoky. City photographs are used with permission or generated for this project. If you believe something here is mis-attributed, please write to hello@sinoky.app and we will correct it.
