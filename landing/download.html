Three download routes — pick the one that matches your device

We list all three rather than hiding the ones that don't apply — plenty of people read this on a computer and then install on their phone.

This looks like your device

① Android phone or tablet — install the APK

This is the only route that downloads a file. Once installed, Sinoky sits in your app drawer like any other app and works offline.

Requires: Android 7.0 or newer (API 24+) Package size: — Permissions: microphone only, and only while you practise
  1. Tap Download above and wait for the file — it will be named something like Sinoky-release.apk.
  2. Open the downloaded file. Android may say installing from unknown sources is blocked → tap Settings → enable Allow from this source → go back.
  3. Tap Install. If you already have an older version, installing over it is fine — your progress is kept.
Got a 0-byte file, or it won't open? Try this page in Chrome instead — some built-in browsers handle APK links badly. And if it still won't install, there's a fallback: just use the web version and “Add to Home Screen”. It's the same product.

② iPhone / iPad — add to Home Screen

iOS can't install APKs. But once you add Sinoky to your Home Screen from Safari, it's near-identical to an installed app: works offline, opens in one tap, full screen with no address bar.

  1. Open this page in Safari (not an in-app browser).
  2. Tap the Share icon in the bottom toolbar (a square with an arrow).
  3. Scroll down and tap Add to Home Screen.
  4. Tap Add — the icon appears on your Home Screen.
Requires: iOS 16.4 or newer for background reminders — older versions work without them

How to confirm the file you downloaded is intact

The package is over 20 MB. An interrupted download gives you no error — just a file that won't install. Comparing checksums takes two seconds.

You should get this value

MD5 checksum, read from the same source as the version card above:

—

How to compute yours

Windows
certutil -hashfile Sinoky-release.apk MD5

macOS
md5 Sinoky-release.apk

Linux
md5sum Sinoky-release.apk

If the two match, the file is intact. If they don't, delete it and download again. On signing: every release is signed with the same key, so a newer version always installs over an older one without the system refusing it.

Another quick check: an APK is a zip archive, so the first two bytes of the file should be PK. If it starts with <!DOCTYPE or similar, you actually downloaded an HTML error page — common on restricted networks or in-app browsers.

How updates work from here

You never have to come back to this page. The app checks for a newer version each time it opens and prompts you if there is one — important releases get a prompt you can't dismiss, with a direct link to the download. Most changes take effect the next time you open Sinoky; occasionally a new package is needed.

Mirrors and older builds

If the direct link doesn't work on your network, the same package is available from GitHub Releases, where older builds are kept too.

If it doesn't work

These cover almost every case we've seen. None of it is your fault — it's browser and OS differences.

The file opens as garbled text or raw HTML You actually downloaded an error page, not a package Check whether it starts with the letters PK (see above)
