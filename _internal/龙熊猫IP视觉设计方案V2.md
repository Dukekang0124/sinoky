# Sinoky 视觉 IP 升级设计方案 V2：「一笔金龙 · 一团和气」（2026-09-10）

> 方向：中国龙 + 熊猫 + 中国经典元素深度融合。
> 一句话：**龙为势，熊猫为核，虚实相生**——龙是中文的深厚（虚、金线一笔），熊猫是初学者的今天（实、圆润居中）。

## 一、设计构思

龙（势/神性/张力）与熊猫（萌/亲和/松弛）同框最大的风险是互相抢戏。解法是**不拼体型拼构图关系**：

- **龙用虚笔**：一根等粗鎏金线的书法式一笔，抽象流动，提供构图骨架与文化气势；不画满爪满鳞，留白即想象。
- **熊猫用实墨**：诺诺本尊，圆润具象，怀抱一枝竹，是视线落点与情感锚点。
- **叙事**：金龙自上环抱而下，熊猫端坐环抱中心——「龙护稚子，一团和气」。神兽守护世界新人开口说中文。

## 二、构图思路

- **S 形龙势**：龙首右上昂起引势入画，龙身一笔书写绕左盘下，尾端在右下卷收，整体是一个未闭合的 C 形环，把视觉焦点「箍」在中央熊猫身上。
- **熊猫居中偏下**：占画面视觉重量约 70%，龙约 30%——龙永远小于熊猫，守护者不做主角。
- **祥云两朵对角**（左上/右下）：对角平衡 + 留白呼吸。
- **朱砂印章左下**：「言」字印，全应用统一文化落款。
- 加载动画：金线沿龙形描线 1.2s（stroke-dashoffset 动画，纯 CSS）。

## 三、统一性四铁律（防元素打架）

1. **比例 7:3**：熊猫主体、龙为环势，任何资产不得颠倒。
2. **线型统一**：细线 2px（纹样）/ 主线 4px（描边图标）/ 龙势 8-16px（仅龙用），全应用一套笔。
3. **三色封顶**：朱砂 #c2362b（点睛/行动）、鎏金 #c9a86c（龙/奖励）、竹青 #8ab8b2（辅助呼吸），其余墨色阶（#161a20 底 → #f5f1e8 纸白）。同屏不超三彩。
4. **纹样分工**：龙鳞=进度成长（动态）；祥云=留白过渡（静态底纹）；回纹=边框收尾（装饰线）；窗格纹=全局底层（已上线）。不混用。

## 四、落地映射（四界面 + 一激励）

| 资产 | 设计 |
|------|------|
| 启动屏/Logo | 完整龙环熊猫构图；加载=金线描龙 1.2s；App 图标=熊猫+龙角极简剪影（小尺寸可辨识） |
| 诺诺双 IP | 熊猫诺诺不变（情感锚点）；新增 Q 版小龙「辰辰」，只在里程碑出现（勋章/7 连/毕业），稀缺出场保新鲜；节庆换装（春节红围巾等）留运营位 |
| 界面纹样 | 祥云=章节过渡底纹；回纹=卡片描边/页脚；龙鳞=进度条分段与勋章形制；窗格纹=全局底层 |
| 激励隐喻 | 30 天课程=「跃龙门」：每天点亮一枚龙鳞，集满 30 鳞化龙毕业（毕业证书=龙形金印）；复习连击=「过龙门」 |
| 朱砂印章 | 「言」印统一落款：加载占位/分享卡片/About/404 |

## 五、实施分期

- **二期（本方案核心交付）**：启动屏龙环熊猫 SVG 插画 + 金线描线加载动画 + App 图标 + 「言」印章组件 + 龙鳞进度条（替换现 pbar）+ 祥云章节分隔
- **三期**：小龙辰辰 IP 资产（AI 生成 Q 版立绘 3-5 姿态）+ 里程碑出场逻辑 + 跃龙门毕业页 + 节庆皮肤位
- 技术约束不变：单文件 PWA、零外部依赖、SVG 内联、深色可读、i18n 不动

## 六、验收口径

- 同屏三色封顶、7:3 比例、线型三档不越界
- 小尺寸（48px 图标）下熊猫仍可辨识
- 老外测试用户能说出「这是中国的 app」且不觉得土（国际化审美）
