# Sinoky 中国风整体视觉与交互升级设计方案（v1.0 · 2026-09-10）

> 主题：「墨韵·朱砂」——学中文的世界场景
> 原则：单文件 PWA 零外部依赖（不引外部字体/图库，全部用系统字体栈 + CSS 原生纹样）；深色为主保证户外可读；国际化审美 = 留白 + 克制，中国元素做氛围不做堆砌。

---

## 一、全局主题「墨韵·朱砂」（CSS 变量层一键换肤）

| 变量 | 旧值 | 新值 | 释义 |
|------|------|------|------|
| --bg | #141a24 | #161a20 | 墨色（暖黑，宣纸墨底） |
| --bg2 | #1b2330 | #1d232c | 淡墨 |
| --card | #1e2735 | #212a35 | 卡片墨青 |
| --line | #2b3648 | #33404c | 描边（微暖） |
| --red | #e63946 | #c2362b | **朱砂/辰砂**（印泥红，更沉稳） |
| --teal | #7fb3b0 | #8ab8b2 | **竹青**（青瓷色微亮） |
| --gold（新增） | — | #c9a86c | **鎏金**（描边/强调/奖励专用） |

- 全应用通过变量层自动换肤，零逐处硬编码。
- 页面底层加**极淡窗格纹**（CSS repeating-linear-gradient 双向网格，透明度 2%，body 多重背景实现，零图片、零请求、离线可用）。
- 标题与汉字大字（h1/h2/.brand/.p-hz/.np-line .hz）加**衬线中文字体栈**：`"Songti SC","STSong","Noto Serif SC","SimSun",serif` → 有宋体墨韵，无则自然回落黑体，老外设备无感降级。
- 勋章 badge 改**印章样式**：圆形朱砂底、白字、金色细环。

## 二、按钮全面胶囊化（一套圆角语言）

统一 `border-radius: 99px`：
- 主/幽灵大按钮 `.btn`（13px → 胶囊）
- 句卡操作钮 `.p-actions .btn`（10px → 胶囊）
- 诺诺面板底部按钮 `.np-foot button`（10px → 胶囊）
- 声调按钮 `.tonebtn`（13px → 胶囊）
- 音节 chip `.syl`、分段器 `.seg`（容器+按钮 → 胶囊）
- 复习模式行 `.rv-mode`、句子重组按钮 `.sent-option/.sent-mode-btn`、录音钮 `.record` 等 → 胶囊
- 反馈浮钮 `#fb-open`（20px → 99px 统一）
- 已是胶囊的保留：`.nm-chip`、`.nctrl-mic`、`.nctrl-txt button`、`.toast`
- 保持不动的圆形钮：`.spk`（喇叭）、`.nctrl-ico`、`.jab`（熊猫快捷钮）——圆钮本身就是胶囊语言的一部分
- 保持卡片样不动的功能入口卡：`.hub`、`.stat`、`.card`（视觉是卡片不是按钮，胶囊会破坏布局）

## 三、诺诺智能助学场景化设计（AI 参与全场景）

诺诺 = 「学伴」不是「老师」：只鼓励、抛问题、给台阶，不纠错不施压（Edify Gate：一切以让用户多说为主路径）。

| 场景 | 诺诺的参与 | 触发时机 | 实施状态 |
|------|-----------|---------|---------|
| **1. 生词学习（Explore 句卡）** | 点开场景时诺诺先示范一句「跟我读」；学完本组句卡（如 4/4）诺诺浮出祝贺 + 抛一句「敢不敢换一个场景试试？」 | 句卡全部 done | 本期实施 ✓ |
| **2. 课文练习（跟读打卡）** | 评分后按分数三档反馈：≥90「地道！」+ 追问扩展句；70-89「很好，慢慢来」；<70 给音节级台阶（已有音节条），诺诺提示「只练标红音节」 | 每次评分后 | 已有基础（cheer/sorry）✓ 本期微调文案分级 |
| **3. 口语对话（自由聊天）** | 已上线 GLM-4-Flash；新增：连续 5 轮对话后诺诺主动夸「你已经会聊天了！」 | chat 轮数计数 | 已有对话，本期加 5 轮彩蛋 |
| **4. 复习闯关（Review）** | 进入复习页诺诺定目标「今天清 8 张卡」；连对 5 张浮出「五连对！🔥」；清空当日到期诺诺放烟花式祝贺 | 进入/连对/清空 | 本期实施连对 ✓ 清空 ✓ |
| **5. 里程碑（streak/勋章/毕业）** | streak 3/7/30 专属祝贺词；勋章解锁已接；毕业典礼已接 | 现有钩子 | 已有 ✓ |

实施原则：每个场景只加一个轻钩子（nonoShow，带 once/priority 防打扰），不打断主流程、不弹模态。

## 四、全球化视野

- 中国元素做「底色」不做「屏障」：纹样/配色/字体是氛围层，所有文案保持 7 门语言（i18n 原文即 key 体系不动）
- 学习内容不变（场景化句子 + 拼音声调色），中国风不增加认知负担
- 胶囊按钮 + 大圆角卡片 = 国际主流移动审美；朱砂/竹青/鎏金 = 文化辨识度
- 深色主题为主，对比度全部保持 WCAG AA
