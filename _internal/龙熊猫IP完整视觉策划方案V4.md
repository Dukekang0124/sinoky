## 1. 整体视觉风格定位

### 1.1 定位：**「水墨为骨，朱砂为魂，鎏金为饰」**

老外打开 Sinoky，第一眼要接收到三层信息，顺序不能乱：

1. **这是一款中国产品**（文化辨识度）→ 由配色、纹样、龙熊猫主视觉在 0.5 秒内完成传达
2. **这是一款现代产品**（可用性信任）→ 由扁平布局、大圆角、清晰的层级与留白完成
3. **这是一款给我用的产品**（国际化友好）→ 由七语 i18n、拼音声调色、不堆砌的装饰完成

**三层信息一旦倒置**（比如先堆满云纹让人看不清按钮），产品就变成了"中国风皮肤"，而不是"学中文工具"。这是本方案所有取舍的总裁判。

### 1.2 三个不做（防"土味中国风"）

| 不做 | 原因 |
|------|------|
| 不做满屏纹理铺底 | 纹样只做 ≤45% 透明度的边角与底纹，绝不叠加在文本区 |
| 不做拟物化卷轴/木纹/宣纸质感 | 拟物材质在深色移动端必土；用**纯 CSS 网格与 SVG 线稿**代替 |
| 不做红金滥用 | 红与金是"重色"，同屏超三彩即失焦；金色只给龙、边框、奖励 |

### 1.3 主题命名与场景映射

主题名 **「墨韵·朱砂」（Night 版，默认深色）**，服务"学中文的世界场景"——夜灯下、通勤地铁里、异国宿舍中。可选后续加 **「宣纸·晴昼」（Light 版）** 作为三期节庆皮肤位，当前不做（避免双主题维护成本）。


### 2.3 同屏三彩规则（硬约束）

任何一屏，**朱砂 / 鎏金 / 竹青 三彩最多同时出现三种，且各自有明确职责**：

- 朱砂＝"要你动手"（点击、录音、选中）
- 鎏金＝"值得庆祝"（奖励、进度、龙）
- 竹青＝"陪着你"（诺诺、辅助、过渡）

第四条彩色（如声调已用的 `--t1~--t4`）只在教学内容区出现（声调色是学习刚需，不算装饰彩）。

### 2.4 对比度红线

正文 `#eef2f7` on `#161a20` ≈ **13:1**（AAA）；次要 `#9aa7b8` ≈ **7:1**（AA+）；金色文字最低限制为标题/大字号，正文不用金色。所有纹样透明度 ≤45%。

## 3. 字体选择

### 3.1 中文字体三级栈（零外部加载，靠系统栈）

| 层级 | 用途 | 字体栈 | 效果 |
|------|------|--------|------|
| **标题衬线** | h1/h2、品牌名、汉字大字（`.p-hz`、`.np-line .hz`） | `"Songti SC","STSong","Noto Serif SC","SimSun",serif` | 宋体墨韵——横细竖粗、有笔锋，一眼"中文" |
| **正文无衬线** | 所有说明、按钮、列表 | `-apple-system,BlinkMacSystemFont,"Segoe UI",Roboto,"PingFang SC","Microsoft YaHei",sans-serif` | iOS/安卓/Windows 各自最优中文黑体 |
| **拼音/数字** | 拼音行、声调标记、统计数字 | 同上 + `font-variant-numeric:tabular-nums; letter-spacing:.5px` | 拼音字母等宽不跳动，数字对齐 |

**为什么不自托管字体**：中文可变字体子集最小也有几百 KB，会破坏单文件 PWA 的离线包体积与首屏速度（铁律）。系统栈方案在 iOS（Songti SC）与 macOS（STSong）都能拿到真宋体，安卓/Win 回落到 Noto Serif SC 或 SimSun，都有衬线感；老外设备若无中文衬线则回落黑体，**降级无损**。

### 3.2 英文与七语兼容

英文文案（i18n 原文）走**标题也衬线、正文无衬线**的同一规则：衬线栈前置 `Georgia,"Times New Roman"` 兜底拉丁字形，让英文标题与中文标题有同一种"书卷气"：

```css
h1,h2,.brand{font-family:Georgia,"Songti SC","Noto Serif SC","SimSun",serif}
```

天城文（暂未）、西里尔（ru）、泰文（th）等字体由各系统默认字体兜底，不做特殊处理——**排版美观不牺牲任何一门语言的正确显示**。

### 3.3 装饰性"书法"的处理

需要书法感的极少数位置（印章"言"、启动屏标语）**不是用字体实现的**，而是内联 SVG 手绘路径——避免依赖用户机器上不存在的书法字体。

## 4. 界面布局与组件样式

### 4.1 布局网格

- 主容器 `.wrap`：`max-width:520px`，左右 16px 安全边距，底部留 90px 给导航
- 垂直节奏：`8 / 12 / 16 / 24 / 32` 五档，全部 rem 化，禁止随意数值
- 圆角语言：**胶囊 99px（一切可点）· 卡片 14px（一切容器）· 角花 22px SVG（装饰）**

### 4.2 组件规范表（V4 终版）

| **Toast / 弹层** | 胶囊 / 14px 圆角 | 金细边 | — |

### 4.3 雕花的实现方式（关键：不是贴图）

所有纹样**用 CSS 或内联 SVG 绘制，零图片请求**：

- **角花**：一张 22×22 的 `background-image:url("data:image/svg+xml,...")`（如意云头单色线稿），通过 `background-position` 贴四角，`background-repeat:no-repeat`——文件里只有一行 base64，不增加网络请求
- **回纹带**：`repeating-linear-gradient` 画方形螺旋的替代简化版，或同样用 data-URI SVG 平铺
- **祥云托底**：纯 CSS 三个圆角矩形拼合（`::before/::after` + border-radius），或 24×8 的 data-URI 云形
- **窗格纹**：已上线的 `repeating-linear-gradient` 双向网格（26px 间距，2% 金）

**优雅降级**：data-URI 解析失败 → 只有描边无角花，界面功能零影响。

### 4.4 可用性红线（违反即回退）

1. 装饰不进文本区；角花外扩不超过组件边缘 2px
2. 纹样透明度 ≤45%，且不得压在正文上
3. 触控目标尺寸完全不变（≥44×44px），装饰绘制在既有边框内
4. 所有动画（描线、龙鳞点亮）时长 ≤600ms 且尊重 `prefers-reduced-motion`
5. 对比度 WCAG AA 起步，正文 AAA

## 6. 诺诺熊猫 IP 形象体系

### 6.1 角色设定

| 项目 | 设定 |
|------|------|
| **名字** | 诺诺（Nono）——"承诺陪你开口" |
| **物种** | 熊猫（黑白，非彩色卡通熊猫，无拟人服装） |
| **性格** | 温和、不评判、有点憨、永远站在你这边（学伴，非老师） |
| **动作习惯** | 抱青竹（身份标识）、眨眼（鼓励）、举竹节（表扬）、捂嘴（害羞/共情） |
| **陪伴龙** | 辰辰——一条幼龙，只在里程碑出现，盘在诺诺身后（稀缺即珍贵） |

### 6.2 表情与姿态库（现状 4 张 → V4 提案 12 张）

**现状**：`assets/mascot/{cheer,like,sorry,think}.webp` 仅 4 张，无法覆盖全场景。

**V4 提案表情矩阵**（webp，256×256，透明底，全站 ≤ 60KB）：

| 情绪组 | 资产名 | 出场场景 |
|--------|--------|---------|
| 鼓励 | `cheer`（举手） | 完成、里程碑 |
| 肯定 | `like`（竖拇指） | 评分 ≥90 |
| 共情 | `sorry`（低头） | 评分偏低、连续失败 |
| 思考 | `think`（抬头望天） | 加载、AI 生成中 |
| **新增** 招手 | `wave` | 每日首次进入、Onboarding |
| **新增** 抱竹坐 | `sit` | 复习页驻场、空状态 |
| **新增** 捂嘴 | `shy` | 用户夸它、彩蛋触发 |
| **新增** 举竹节 | `praise` | 五连对、连对连击 |
| **新增** 眼睛发亮 | `wow` | 首次开口、首次完成场景 |
| **新增** 打瞌睡 | `sleep` | 离线态、长时间无操作 |
| **新增** 递竹简 | `invite` | 引导下一个动作（"再试一句？"） |
| **新增** 龙鳞徽 | `legend`（+辰辰） | 30 天毕业、大里程碑 |

> 生成方式：以现有 4 张为风格基准，用同一提示词模板批量生成 + 人工过目；或程序化合成（现有 webp 的造型语言较复杂，建议 AI 生成 + 底色透明化）。

### 6.3 IP 使用铁律

1. **诺诺永远是"最靠近用户"的角色**——它的表情永远先于文字被看到（气泡头像 + 页面驻场位）
2. **辰辰永远稀缺**——只在里程碑出场，日常不出现；一出场就是大事
3. **诺诺不纠错**——低分时用 `sorry` + 台阶（"只练标红音节"），绝不显示 ✗ 或红叉
4. **不拟人化过度**——不给诺诺加服装、不开口说话时配嘴型动画（静态 webp 即可）
5. **比例恒定**——任何画面诺诺占视觉重量 60%，龙/辰辰 40% 且不与诺诺等高

## 10. 验收口径

| 维度 | 通过标准 |
