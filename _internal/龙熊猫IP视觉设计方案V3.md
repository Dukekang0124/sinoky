# Sinoky 视觉设计方案 V3：「金龙盘诺诺 · 雕梁画栋」（2026-09-10）

> V2 反馈：思路保留，视觉执行不佳（金线虚笔的龙过于简陋）。V3 推倒重做执行层：
> ① 龙改为 Q 版实心厚绘，与熊猫同一套造型语言；② UI 组件引入古建筑雕刻纹样。

## 一、主视觉：金龙盘诺诺

**风格统一的关键**：龙与熊猫共用同一套造型语言——「粗深描边 + 圆润浅填充 + 大眼简洁五官」。龙不是书法虚笔，而是和诺诺一样可抱可摸的 Q 版角色，只是体型盘绕、色用鎏金。

- **龙**：鎏金身 #c9a86c / 深棕描边 #6b5527 / 浅金腹线 #e8d9b0 / 朱砂背鳍 #c2362b（与印章同色呼应）/ 朱砂卷须 / 怀抱戏珠。
- **诺诺**：黑白熊猫不变，怀中竖竹（竹青 #8ab8b2），居中端坐。
- **构图**：龙身两段式盘绕——后段从左下绕过头顶到右侧（在诺诺身后），前段从右侧下绕至身前（遮挡诺诺身体一角），龙头在右下仰头含珠。前后遮挡产生「盘了一圈」的立体感。
- **配景**：竹青祥云三朵对角留白、底部回纹带 + 金线、「言」字朱砂印章。
- **比例**：诺诺视觉重量约 60%、龙盘绕约 40%（V2 的 7:3 调整——龙改实心后可略增，但头永远低于诺诺视线、不抢表情）。

## 二、组件纹样：古建雕花「边角施艺，中央留白」

装饰只出现在**边缘、四角、选中态**，内容区永远素净。四类组件语言：

| 组件 | 纹样 | 实现 |
|------|------|------|
| 卡片边框 | 金线单描边 + 四角如意云头角花（22px SVG，absolute 四角） | 角花只占边缘 2px，正文零影响 |
| 分隔线 | 回纹带（greek key 方形螺旋）+ 中央朱砂圆点 | 章节过渡、设置分组 |
| 按钮 | 胶囊形不变；主按钮朱砂底 + **内嵌金环**（inset box-shadow）；幽灵按钮金边 | 雕刻感来自双层线，不加纹理 |
| 底部导航 | 顶部金线；**选中项祥云托底**（朱砂云形浮标）；未选中灰度 | 祥云只出现在选中态，克制 |
| 全局底层 | 窗格纹（已上线）保留 | 2% 透明度 |

## 三、可用性红线（装饰不影响可读与操作）

1. 所有纹样透明度 ≤45%，不进入文本区；
2. 纹样不随内容滚动（fixed 或组件内固定位）；
3. 触控目标尺寸完全不变（纹样绘制在既有边框内）；
4. 优雅降级：SVG 纹样渲染失败 = 不显示，界面功能照常；
5. 对比度维持 WCAG AA（正文 #eef2f7 on #161a20 ≈ 13:1）。

## 四、配色总表（三彩 + 墨阶，同屏不超三彩）

朱砂 #c2362b（点睛/行动/背鳍/印章）· 鎏金 #c9a86c（龙/边框/奖励）· 竹青 #8ab8b2（辅助/祥云/竹）· 墨阶 #12161c→#f5f1e8。
