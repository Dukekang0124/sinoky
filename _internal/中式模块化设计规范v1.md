# Sinoky 中式模块化设计规范（模块设计语言 v1.0）

> 日期：2026-09-11 · 配套样张：① 纹样母题库 ② 八类模块样张 ③ 版式与适配规范
> 定位：**页面级视觉稿之下的「模块级设计语言」**——把 6 个纹样单位元装配成可复用的 UI 模块规格，供评审与实施。

---

## 零、先回答你的确认问题

**V4 的「图片视觉设计」部分没有做模块化。** 事实依据：

| 项 | 实情 |
|---|---|
| V4 §8 的产出粒度 | 6 张**页面级**视觉稿（P1 启动屏 / P2 首页 / P3 跟读 / P4 诺诺面板 / P5 复习 / P6 毕业）+ 素材三分类 —— 粒度是"页面"，不是"模块" |
| 纹样落地情况 | 审计实测：6 种纹样**一个都没实施**（`data:image/svg+xml` 在线上出现 **0** 次；卡片角花 / 回纹分隔 / 导航祥云 / 按钮金环 全未做） |
| 缺口本质 | 缺的不是"更好看的页面稿"，而是**中间层**：把中式视觉拆成可复用模块，才能一致地铺到 16 个视图 |

本规范补的就是这个中间层。

## 一、调研结论：中式模块设计的高阶范式

### 1.1 四条可落地的范式（来自检索，附来源要点）

| # | 范式 | 内容 | 来源要点 |
|---|------|------|---------|
| 1 | **边饰优先律** | 传统纹样在 UI 中的正统承载者是**「边」**（二方连续边饰），不是「面」（满铺纹理）。边饰纹样在数字设计中的三类正统落点即：**标题框、按钮边框、分割线**；其次才是边角装饰与底纹 | 边饰纹样（二方连续）考证 + 现代应用场景列举 |
| 2 | **一纹一职律** | 传统纹样现代转化三步法：**解构**（提取构成规律）→ **夸张简化**（保留识别特征、删细部）→ **变形重组**（获得现代形态）。落到 UI：**每种纹样只承担一种语义职能**，不混用、不叠用 | 中国传统纹样在手机 UI 中的应用方法研究 |
| 3 | **墨分五色 / 三阶景深律** | 新中式的配色要义是**雅致沉稳、低饱和、少而精**（主色 1 + 辅助 1），避开大红大绿；用透明度分层模拟水墨景深 | 新中式 VI 方法论 / 东方神韵设计手法 |
| 4 | **逻辑填充律（矢量自适应）** | 位图平铺有**三大硬伤**：拉伸失真、加载冗余、纹路断裂。正解是 **SVG 定义单位元 + CSS 变量控制 `background-size` + `mask-image` 处理边缘**——"把纹饰从图像变成指令" | 古典纹饰的数字重构工程范式 |

### 1.2 我采纳什么、不采纳什么

**采纳**：边饰优先 · 一纹一职 · 三阶景深 · 逻辑填充。这四条正好匹配"单文件 PWA + 零外部请求 + 深色 + 全球用户"的硬约束。

**不采纳**（对工具类 App 过重、或跨文化易误导）：
- 五正色全套体系、卷轴展开转场、失蜡法/缂丝材质模拟 —— 移动端信息密度下是负担
- 「香炷燃烧」「水流注满」式进度条 —— 认知成本高于收益，且隐喻需文化背景才懂

**主动排除一项传统文化元素**：**卍字纹**。它在中华传统纹样中完全正当（吉祥符），但面向全球中文学习者（含欧美用户），存在被误读为纳粹符号的现实风险。**改用方胜纹 / 龟背纹 / 冰裂纹**——同样传统、无歧义。这是本地化风险判断，不是审美取舍。

## 二、纹样母题库（6 个单位元，全部为 SVG 单位元）

| 纹样 | 职能 | 单位元尺寸 | 用法 |
|------|------|-----------|------|
| **回纹带** | 收边 / 分隔 | 8×7px（小）/ 26×22px（大） | 卡片底边、模块断点、标题带、导航收尾 |
| **如意云头** | 四角起止 | 12–22px | 卡片四角、面板四角 |
| **祥云** | 状态浮起 | 28×8px | 仅底部导航选中项托底 |
| **冰裂纹** | 底纹 / 肌理 | 不规则多边形 | 空态插画区、大片留白处（28% 透明） |
| **方胜纹** | 底纹 · 几何规整 | 34×34px | 分区背景（42% 透明） |
| **龙鳞** | 进度 / 成长 | 单元 11×6px | 30 天进度、数据条 |

**共性铁律**：全部以 SVG 单位元定义，非位图；单色（金 `#c9a86c`），靠透明度分层；描边式而非填充式（描边不压内容）。

## 三、模块设计规范（10 类 · 视觉元素 / 配色 / 版式 / 适配）

### M1 卡片（首页功能入口 / 内容卡）

| 维度 | 规格 |
|------|------|
| **视觉元素** | 四角**如意云头**（12px，仅描边）+ 底边**回纹带**（8px，35% 透明）+ 1px 金描边（暗金） |
| **配色** | 底 `--card #212a35`；描边 金 45%；标题 `--txt`；副标 `--sub` |
| **版式** | 圆角 18px；内距 14px；最小高 72px；图标 20–24px；标题左对齐、副标下一行 |
| **适配** | 宽 < 360px 时角花缩至 14px；回纹带宽 = 容器宽（单元固定 8px，靠数量适配）；纹样永不进入内容区 |

### M2 列表行（天数行 / 设置项 / 场景行）

| 维度 | 规格 |
|------|------|
| **视觉元素** | 左**朱砂竖线** 3px（**仅当前/高亮行**）+ 断点用**回纹 + 中央朱砂圆点**（替代传统分割线） |
| **配色** | 竖线 朱砂；断点纹 金 30% + 朱砂点；主文 `--txt`；副文 `--sub` |
| **版式** | 行高 56px；左内距 14px（竖线占 3px）；文字左对齐、右侧箭头 |
| **适配** | 断点纹居中对称；宽 < 360px 时只保留朱砂圆点（去回纹）；锁定行整行 45% 透明 |

### M3 按钮（主 / 幽灵 / 圆形 / chip）

| 维度 | 规格 |
|------|------|
| **视觉元素** | 主钮 = 朱砂胶囊 + **内嵌金环**（`inset 0 0 0 1px`，非外描边）；幽灵钮 = 1px 暗金边；圆形钮 = 金环；chip = 金胶囊 |
| **配色** | 主 朱砂底 + 白字；幽灵 透明 + 暗金边 + `--txt`；圆形钮 + / chip 金 |
| **版式** | 高 **≥44px**（触控下限）；圆角 99px；横向内距 16–20px；字重 500 |
| **适配** | 长文案截断不换行；窄屏最小高保 44px；主钮不因文案变高 |

### M4 底部导航

| 维度 | 规格 |
|------|------|
| **视觉元素** | 顶部 **1px 金线** + **选中项祥云托底** + 右端**回纹段**收尾 |
| **配色** | 选中 朱砂（图标+文字）；未选 `--sub`；金线 45%；祥云 朱砂 |
| **版式** | 高 58px + 安全区；5 项等分；图标 20–24px；文字 10px |
| **适配** | **祥云尺寸不随屏宽变化**（状态标识，非装饰）；>420px 导航居中留白；选中态只允许一个 |

### M5 标题区（页面头 / 章节标题）

| 维度 | 规格 |
|------|------|
| **视觉元素** | **回纹带** + 金线 + **中央朱砂圆点** + 宋体标题 + 右侧**落款印**（22×22） |
| **配色** | 标题 `--paper #f5f1e8`；纹 金 45%；圆点 朱砂；印 朱砂底 + 金边 + 宣纸白字 |
| **版式** | 标题 16–27px 衬线；副标 10–13px；印与标题基线对齐 |
| **适配** | 纹样带宽 = 容器；标题过长（>10 字）时纹样带移到标题上方，印移至右下 |

### M6 数据块（统计 / 进度）

| 维度 | 规格 |
|------|------|
| **视觉元素** | 大号数字（`tabular-nums` 等宽）+ **龙鳞进度条** |
| **配色** | 数字 `--paper`；标签 `--sub`；龙鳞 已亮 金 95% → 未亮 金 20%（五档渐变） |
| **版式** | 数字 19–24px；标签 9.5–11px；鳞片单元 11×6px |
| **适配** | 鳞片数 = 业务天数（30 天=30 鳞）；容器变窄时**缩间距不缩鳞片**；窄屏可折行 |

### M7 徽章 / 印章

| 维度 | 规格 |
|------|------|
| **视觉元素** | 圆形实底 + 金环 + **内圈 0.8px 细线** + 中央字（言/汉 等） |
| **配色** | 已解锁：朱砂底 + 金环 + 宣纸白字；未解锁：`--card` 底 + **暗金虚线环** + 暗金字 |
| **版式** | 直径 44–56px；内圈离边 6px；下方 10px 标签 |
| **适配** | **直径固定，不随屏缩放**；一行最多 4 枚，超出换行 |

### M8 浮层（诺诺气泡 / toast / 弹层）

| 维度 | 规格 |
|------|------|
| **视觉元素** | 气泡 = 圆角 18px + **单角 5px 尖角**（诺诺左下 / 用户右下）+ 尾部小三角；toast = 金边胶囊 |
| **配色** | 诺诺 竹青浅底 `#1b2b2e` + `--sub` 文字；用户 朱砂底 + 白字；toast `--card` + 暗金边 |
| **版式** | 气泡内距 10×13px；字号 13.5px / 行高 1.55；toast 高 24px 胶囊 |
| **适配** | 气泡 `max-width: 76%`；长文案自动换行；toast 单行截断 |

### M9 空态 / 加载

| 维度 | 规格 |
|------|------|
| **视觉元素** | 诺诺坐姿插画 + **冰裂纹底纹**（28%）+ 一句引导 + 一个主钮 |
| **配色** | 底纹 金 28%；引导文 `--sub`；按钮按 M3 |
| **版式** | 整体居中；插画 120–160px；文案与按钮间距 12px |
| **适配** | 插画等比缩放；**底纹只铺插画区域**，不铺满屏；加载态用描线/淡入，不用 spinner |

### M10 分段器 / 表单

| 维度 | 规格 |
|------|------|
| **视觉元素** | seg = 金胶囊容器 + 选中项朱砂 12% 底 + 朱砂字；输入框 = 99px 胶囊 + **内嵌金线** |
| **配色** | 选中 朱砂；未选 `--sub`；输入框底 `--bg2`；聚焦金线转亮金 |
| **版式** | 高 40–44px；seg 内距 4px；输入框内距 12px |
| **适配** | 段数 > 3 时横向滚动不压缩；输入框高不随字号变 |

## 四、配色映射表（同屏三彩封顶的执行细则）

| 色 | 变量 | 值 | 在模块中的职责 | **禁止** |
|---|---|---|---|---|
| 朱砂 | `--red` | `#c2362b` | 行动 / 选中 / 印章 / 竖线 / 落点 | **禁止作小字正文**（对比度实测 3.21:1 不达标） |
| 鎏金 | `--gold` | `#c9a86c` | 纹样 / 描边 / 进度 / 奖励 | 禁止做大面积实底（只做线与描边） |
| 暗金 | `--gold-dim` | `#8a7448` | 非活动态纹样 / 次按钮边 / 锁定态 | — |
| 竹青 | `--teal` | `#8ab8b2` | 诺诺 / 辅助 / 祥云 | 禁止与朱砂同权重同屏 |
| 宣纸白 | `--paper` | `#f5f1e8` | 大字号 / 印章内字 / 高光 | 禁止作正文（刺眼） |
| 墨阶 | `--bg/--bg2/--card/--line` | `#161a20/#1d232c/#212a35/#33404c` | 底 / 次底 / 卡 / 描边 | — |
| 正文 | `--txt/--sub` | `#eef2f7/#9aa7b8` | 正文 / 次要 | — |

**透明度三阶（墨分五色的落法）**：`0.70` 主纹（近景，如选中祥云）· `0.45` 辅纹（中景，如角花/回纹带）· `0.28` 底纹（远景，如冰裂/方胜）。

**同屏三彩封顶**：任意一屏，朱砂 / 鎏金 / 竹青三彩最多同时出现三种，各自职责固定（朱砂=要你动手，鎏金=值得庆祝，竹青=陪着你）。纹样用金，**不额外引入第四彩**。

## 五、适配规范

| 维度 | 规则 |
|------|------|
| **纹样缩放** | 单位元尺寸**恒定**（回纹 8×7px / 角花 12px / 祥云 28×8px / 鳞 11×6px）；容器变宽 → **增加重复次数**，绝不拉伸单位元 |
| **实现方式** | `background-image: url("data:image/svg+xml,...")` + `background-repeat: repeat`；`background-size` 固定为单位元尺寸；边缘用 `mask-image: linear-gradient(...)` 收口，避免纹路被容器硬截断 |
| **断点** | `<360px` 精简纹样（去回纹去角花，只留竖线/圆点）；`360–520px` 完整纹样；`>520px` 容器 520px 居中 + 两侧留白 |
| **触控** | 一律 ≥44×44px；纹样绘制在既有边框内，**不改变触控目标尺寸** |
| **文字安全区** | 纹样一律不进文本区；角花外扩不超过组件边缘 2px |
| **对比度** | 正文 ≥13:1（实测 15.53:1）；纹样不得压在正文上，压不到即不参与对比度计算 |
| **动画** | 纹样本身不做动效；状态变化（祥云浮现 / 鳞片点亮）≤600ms，且尊重 `prefers-reduced-motion` |
| **性能** | 全部内联/`data-URI` SVG，**新增网络请求 0**；单模块纹样体积 < 1KB |
| **优雅降级** | `data-URI` 解析失败 → 只剩描边，功能零影响 |

## 七、验收口径

1. **同屏纹样 ≤ 2 种**，且不同阶（如 0.45 回纹 + 0.28 底纹，不可 0.45+0.45）
2. **纹样不压正文**，任何字号下正文区域 ✅ 无纹样
3. **任意视口纹样线宽恒定**（1px 永远 1px，不随容器缩放）
4. **触控目标尺寸不变**，全部 ≥44px
5. **对比度不降**（正文仍 ≥13:1）
6. **新增网络请求 = 0**，单模块纹样 < 1KB
7. **移动端 4 端一致**：iOS Safari / Android Chrome / 微信 X5 / APK WebView
8. **可降级**：纹样失效即只剩描边，界面照常可用
