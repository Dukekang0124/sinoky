# 新诺诺聊天框设计方案（v0.14.8）

## 1. 核心问题

测试阶段发现 `#nono-chat` 内的对话气泡无限向下撑开，导致整个 `#nono-panel` 越来越高，最终铺满屏幕、挤占底部导航。

## 2. 解决策略

- **全局约束**：`#nono-panel` 设置 `max-height: calc(100dvh - 170px)`，使用 `display:flex; flex-direction:column` 构建固定头部/可滚动内容区/固定底部。
- **聊天区独立滚动**：`#nono-chat` 内部新增 `.nc-scroll` 滚动容器，限制最大高度并 `overflow-y:auto`，新增消息自动滚动到底部。
- **面板生命周期**：切换到「自由聊天」时，`#nono-chat` 占满剩余空间；切换到「跟读练习」时恢复原有布局。

## 3. 视觉方向：竹影窗棂

| 元素 | 设计 |
|------|------|
| 主色 | 黛青 `#18202b`、牙白 `#f9f4ee`、朱砂 `#c2362b`、金 `#c9a86c`、竹青 `#7fb3b0` |
| 面板 | 深黛底 + 金色单边框 + 轻微外发光 |
| 气泡-诺诺 | 水青渐变 + 左下尖角 + 左侧竹节竖线 |
| 气泡-用户 | 朱砂红渐变 + 右下尖角 |
| 气泡-系统 | 居中半透明药丸 |
| 模式切换 | 顶部分段胶囊「练习｜聊天」，选中金色 |
| 控制区 | 大型圆形麦克风按钮（录音时红脉动）+ 小图标键 |

## 4. 交互改进

- 自动滚动：每次新增气泡/打开聊天时滚动到底部。
- 键盘适配：移动端弹出输入法时，`#nono-chat` 高度自动压缩，发送按钮始终可见。
- 录音反馈：按住麦克风时按钮放大并呈现红色涟漪动画。

## 5. 实现范围

仅修改 `index.html` 中的 CSS 与 JS，不改动 `_worker.js` 和后端。
